# Discard — Comete brand kit

Approved direction: Orbite 10 / Comete, selected on 2026-10-25.
An open circular route and a soft comet-shaped satellite identify a focused,
independent desktop home for Discord Web. Keep the shape intact; do not turn it
into a controller face or imply that Discard is an official Discord product.

Use the primary pair on light surfaces and the night pair on dark surfaces.
Purple and white mono versions are provided; solid black is not a brand treatment.
Do not recolour one half arbitrarily, add gradients, outlines, glow or shadows.
Print CMYK/Pantone matching is not specified or verified in this digital-first kit.

## Marks and sizes

The editable master is discard-symbol.svg. Horizontal, stacked and wordmark-only
SVGs contain original path lettering, not linked fonts or embedded raster artwork.
Keep at least half the ring band (24/256 of symbol canvas) clear around the mark.
Minimum symbol canvas: 16 px for tray/favicon, preferably 24 px or larger. Minimum
horizontal signature width: 180 px. Never stretch, crop the satellite or close
the opening. Scale the complete SVG with its aspect ratio preserved.

## Typography and voice

The custom lowercase wordmark is artwork, not an installable font. Product and
editorial text use the local system UI family: Segoe UI on Windows, system-ui
elsewhere, with sans-serif fallback. No font binaries are redistributed.
Use short, direct English in the README and distribution material; avoid claimed
CPU/RAM/FPS improvements without measurements. Tagline: Your conversations. Your space.

## Applications and files

- Light/dark colour, purple mono and white symbol masters.
- Horizontal light/dark, stacked and wordmark SVGs.
- Transparent 1024 px symbols, web icons, favicon and webmanifest.
- README banner and 1280x630 social preview, in SVG and PNG.
- App/tray/bundle icons live in assets/icons; Windows setup uses assets/icon.ico.

The README banner/social SVGs use system text for the tagline, while the logo
wordmark itself is outlined. PNG copies freeze those presentation layouts.
Do not replace Discord-owned UI with this mark or change user/session data.

## Validation and limits

Actual SVGs were statically rendered and visually inspected, including 16/32/64 px
previews in concept review. Export structures/sizes are checked during delivery.
No desktop application was launched. Build success does not prove Windows cache,
tray/taskbar rendering or installed shortcuts visually refresh correctly.
Trademark clearance and exhaustive similarity search are not established.
